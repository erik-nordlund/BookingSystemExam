# Booking System – individual coding exam

This is a starter project for the individual practical coding exam. The
application targets .NET 10 and contains a console application and xUnit tests.

## Requirements

- .NET 10 SDK

## Run the application

Open a terminal in the project root folder and run:

```bash
dotnet run --project src/BookingSystem
```

You can also open BookingSystemExam.slnx in Visual Studio and start the application with Ctrl + F5.

## Run the tests

Open a terminal in the project root folder and run:

```bash
dotnet test
```

You can also run the tests in Visual Studio using Test Explorer.
